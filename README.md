# OpenTCM 增强版 - 智能辨证分析系统

## 🎯 项目概述

OpenTCM增强版针对"中医知识图谱构建：整合《黄帝内经》《伤寒杂病论》等经典医籍与现代临床数据，结合大语言模型（LLM）构建动态中医知识图谱，实现舌象、脉象、症状的智能辨证分析，支持中医诊断逻辑的可解释性推导"赛题需求进行了全面升级。

## 🚀 主要改进

### 1. 📚 经典医籍数据整合

**问题**：原项目只有《伤寒论》，缺少核心经典医籍

**解决方案**：
- 新增支持《黄帝内经》《伤寒杂病论》《金匮要略》等核心经典
- 创建`enhanced_TCMKG.py`增强版知识图谱构建系统
- 优化的文本分块和章节识别算法
- 支持多种古籍格式的智能解析

### 2. 🩺 舌象、脉象、症状智能辨证

**问题**：原项目三元关系未重点关注辨证分析

**解决方案**：
- 设计专门的辨证分析关系类型：
  - 舌象关系：`疾病导致舌象`、`证候导致舌象`、`舌象表现特征`
  - 脉象关系：`疾病导致脉象`、`证候导致脉象`、`脉象表现特征`
  - 症状关系：`疾病表现症状`、`症状伴随症状`
  - 辨证关系：`症状辨证证候`、`舌象辨证证候`、`脉象辨证证候`、`综合辨证证候`

### 3. 🔬 现代临床数据结合

**问题**：现代名医临床数据未与知识图谱结合

**解决方案**：
- 整合`data/medical_case`下的现代临床病例
- 创建临床病例专用处理流程
- 建立`临床验证理论`关系，连接经典理论与现代实践
- 支持名医经验的结构化提取

### 4. 🧠 智能辨证分析系统

**新增功能**：
- `smart_diagnosis.py` - 专门的智能辨证分析模块
- 自动提取症状、舌象、脉象特征
- 基于知识图谱的智能证候推理
- 可解释的诊断逻辑推导
- 个性化治疗建议生成

### 5. ⚡ 增强版GraphRAG系统

**改进特性**：
- `enhanced_GraphRAG.py` - 升级版问答系统
- 智能意图识别，自动切换辨证/一般查询模式
- 针对性知识检索策略
- 流式响应优化
- 多源知识融合

## 🛠️ 使用指南

### 步骤1：准备数据

1. **补充经典医籍**：
   - 将《黄帝内经》《金匮要略》等经典文本文件放入`data/src/classicals/`目录
   - 确保文件格式为UTF-8编码的.txt文件

2. **检查临床数据**：
   - 确保`data/medical_case/`目录包含名医病例数据

### 步骤2：构建增强版知识图谱

```bash
# 运行增强版知识图谱构建系统
python enhanced_TCMKG.py
```

这将：
- 自动处理所有经典医籍和临床病例
- 提取辨证相关的三元关系
- 生成`tcm_enhanced_KG.csv`文件
- 支持断点续传，处理中断后可继续

### 步骤3：启动Web应用

```bash
# 启动增强版Web应用
python app.py
```

系统将：
- 自动检测并使用增强版功能
- 在`http://localhost:8000`提供服务
- 支持智能辨证分析和一般知识查询
